# Design System

## Visual Identity

laVilla SB targets a skateboarding audience. The visual direction is dark, bold, and gritty, inspired by Creature Skateboards.

## Color Palette

| Token | Hex | Usage |
|-------|-----|-------|
| `--color-bg` | `#0a0a0a` | Primary background |
| `--color-surface` | `#141414` | Cards, panels |
| `--color-surface-elevated` | `#1f1f1f` | Elevated surfaces |
| `--color-text` | `#f5f5f5` | Primary text |
| `--color-text-muted` | `#a3a3a3` | Secondary text |
| `--color-accent` | `#84cc16` | Lime green accent (CTAs, highlights) |
| `--color-accent-hover` | `#a3e635` | Accent hover state |
| `--color-border` | `#262626` | Subtle borders |
| `--color-danger` | `#ef4444` | Errors, destructive actions |

## Typography

- **Headings**: Inter or a bold condensed skate-style font (e.g., Bebas Neue) for headlines.
- **Body**: Inter, system sans-serif fallback.
- **Sizing**: Large, impactful headings; readable body copy at 16px base.

## Components

- Buttons: high-contrast, rounded-md, lime accent for primary actions.
- Cards: dark surface, subtle border, hover lift with shadow.
- Forms: minimal, dark inputs with clear focus rings.

## Motion

- Use Framer Motion for page transitions, cart animations, and hover micro-interactions.
- Keep animations snappy (200–300ms) to match the energetic brand.
